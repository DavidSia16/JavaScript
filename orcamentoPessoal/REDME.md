# 🆔 Verificador de Idade

Este é um projeto simples feito em **JavaScript** para treinar manipulação de código e imagens na tela.

---

## 📌 O que a página faz?

1. O usuário digita o **ano em que nasceu**.
2. Seleciona o **sexo** (Masculino ou Feminino).
3. Clica no botão **Verificar**.
4. O programa calcula a idade e mostra na tela **uma mensagem e uma foto** de acordo com a faixa etária (bebê, jovem, adulto ou idoso).

---

## 🛠️ Tecnologias Usadas

* **HTML5:** Estrutura da página
* **CSS3:** Estilos e cores
* **JavaScript:** Lógica do programa

---

## 📁 Como rodar no seu computador

1. Baixe os arquivos do projeto.
2. Abra o arquivo `modelo.html` em qualquer navegador (Chrome, Edge, Firefox, etc.).
