# 💰 Calculadora de Orçamento Pessoal

> Projeto desenvolvido para praticar os conceitos fundamentais de JavaScript aprendidos na **Aula 6 (Tratamento de Dados)** do curso da [Curso em Vídeo](https://www.cursoemvideo.com/).

---

## 📌 Sobre o Projeto

A **Calculadora de Orçamento Pessoal** é uma aplicação web simples e interativa que ajuda o usuário a calcular seu saldo mensal e visualizar a porcentagem da renda gasta em despesas. 

O objetivo principal deste repositório foi aplicar conceitos essenciais de manipulação e tratamento de dados no front-end usando JavaScript puro.

---

## ⚙️ Funcionalidades

- 📥 **Entrada de dados interativa:** Captura de dados com `window.prompt()`.
- 🔄 **Conversão e validação:** Tratamento de strings para números (`Number()`, `.replace()`) e validação de `NaN`.
- 🔠 **Manipulação de texto:** Formatação do nome em caixa alta (`.toUpperCase()`).
- 💵 **Formatação monetária:** Exibição dos valores no padrão de moeda brasileira (R$) com `.toLocaleString('pt-BR', { style: 'currency', currency: 'BRL' })`.
- 📊 **Feedback visual:** Destaque em verde para saldo positivo e vermelho para saldo negativo.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estruturação do projeto.
- **CSS3** — Estilização moderna com layout responsivo e gradiente.
- **JavaScript (Vanilla)** — Lógica, tratamento de dados e manipulação do DOM.
